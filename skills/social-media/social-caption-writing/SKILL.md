This skill turns a raw topic or brief into a platform-correct post using a consistent Hook → Value → CTA structure. It respects each platform's real length and style constraints so that the generated copy is ready to publish without breaking layout or feed previews.

## Step 1 — Confirm platform and goal

Required before drafting:
1. **Platform**: Instagram, LinkedIn, X, or Facebook.
2. **Goal**: Awareness, engagement, conversion, education, or announcement.

If either is missing, ask the user once to clarify rather than guessing.

## Step 2 — Apply platform rules

| Platform | Length guide | Style notes |
|---|---|---|
| Instagram | Hook visible in first 125–150 chars; full caption up to 2,200 chars | Hook first line, CTA last line |
| X / Twitter | ≤280 chars per post | One clear point; thread if it needs more |
| LinkedIn | 150–300 words | Value-first, no clickbait, use line breaks |
| Facebook | 40–80 words performs best | Conversational, question-based CTAs |

## Step 3 — Structure: Hook → Value → CTA

1. **Hook** (line 1): a question, bold claim, or relatable pain point that stops the scroll
2. **Value** (body): the actual insight, story, or offer — kept tight, no filler
3. **CTA** (final line): one clear action — comment, share, click, save, sign up

## Step 4 — Output format

```text
PLATFORM: <name>
---
<caption copy>
---
NOTES: <length check, any platform-specific formatting notes>
```

## Common failure modes

- **Burying the hook**: putting context or a greeting before the hook line, which gets truncated in feed previews (especially Instagram/Facebook) so the actual hook never gets seen.
- **Stacking multiple CTAs**: asking readers to "comment, share, AND click the link" in one post, which dilutes response and confuses what action matters most.
- **Ignoring platform length as a suggestion**: writing a 400-word LinkedIn post when 150–300 is the performing range, or writing an Instagram caption as if it were a blog post, causing feed truncation or reader drop-off.
- **Formality mismatch**: applying LinkedIn's more formal, value-first structure directly to Facebook or Instagram without adjusting tone, producing copy that reads stiff on casual platforms.
