---
name: content-repurposing
description: Use when a long-form asset — a blog post, video transcript, or document — needs to be turned into multiple platform-native social posts (LinkedIn, X, Instagram, or a reel script) instead of being copied or lightly edited.
---

This skill extracts the strongest, most standalone moments from long-form content and rewrites each one as a native post for a different platform. It ensures the content is adapted for its specific destination rather than summarizing or copying the source directly.

## Step 1 — Extract insights

Read the full source material and pull out 3–5 standalone insights, stats, quotes, or moments that could work independently of the full piece. Each one should make sense without needing the rest of the article for context.

## Step 2 — Match insight to platform

| Insight type | Best platform | Format |
|---|---|---|
| Most value-dense insight | LinkedIn | Post, 150–300 words, value-first |
| Punchiest one-liner | X / Twitter | Post or short thread |
| Most visual/demonstrable point | Reels / Shorts | Reel script (see `reel-script-generation`) |
| Relatable or discussion-provoking point | Instagram / Facebook | Caption |

## Step 3 — Rewrite, never copy

For each platform output:
1. Rewrite fully in that platform's native voice and length — do not lift sentences verbatim from the source
2. Drop source-specific framing ("as we discussed in this post...") — each output must stand alone
3. Keep only the facts/claims that are actually present in the source material

## Step 4 — Output format

Repeat once per platform:
```text
SOURCE INSIGHT: <one line describing which point this came from>
PLATFORM: <name>
---
<rewritten copy or script>
---
```

## Common failure modes

- **Near-verbatim rewrites**: changing a few words but keeping the source's sentence structure intact, which reads as thin repurposing rather than platform-native content and can look like duplicate content across channels.
- **Losing standalone context**: repurposing a point that only makes sense with surrounding context from the original piece, leaving readers of the social post confused.
- **One-size-fits-all repurposing**: using the same extracted insight and near-identical phrasing across all platforms instead of matching each insight to the platform it fits best.
- **Fabricating detail to fill gaps**: adding specifics (numbers, examples) not present in the source material to make a repurposed post feel more complete — always flag thin source material instead of inventing detail.
