# Collection — Yazhi operating system

For people and agents working *inside* Yazhi: values, status, code pipeline, review gates, and releases.

## Start here

| Task | Skills |
|---|---|
| Orient in a repository | [`yazhi-code-orient`](../skills/yazhi-code/yazhi-code-orient/SKILL.md), then the repo's own docs |
| Start a contributor session | [`yazhi-work-start`](../skills/org/yazhi-work-start/SKILL.md), then [`yazhi-code-orient`](../skills/yazhi-code/yazhi-code-orient/SKILL.md) |
| Decide if a feature belongs | [`yazhi-purpose-gate`](../skills/yazhi-purpose/yazhi-purpose-gate/SKILL.md) |
| Run a change from idea to client | [`yazhi-work-start`](../skills/org/yazhi-work-start/SKILL.md) → [`yazhi-code-orient`](../skills/yazhi-code/yazhi-code-orient/SKILL.md) → `frame` → `design` → `implement` → `handoff` → `deliver` |
| Final verdict before merge | [`yazhi-review`](../skills/yazhi-purpose/yazhi-review/SKILL.md) |
| Run the organization cadence | [`yazhi-ops`](../skills/org/yazhi-ops/SKILL.md), [`yazhi-daily-rhythm`](../skills/org/yazhi-daily-rhythm/SKILL.md) |
| Daily PR/issue status | [`yazhi-work-status`](../skills/org/yazhi-work-status/SKILL.md) → [`yazhi-code-action`](../skills/yazhi-code/yazhi-code-action/SKILL.md) |
| Draft an issue or PR | [`yazhi-code-writeup`](../skills/yazhi-code/yazhi-code-writeup/SKILL.md) |
| Ship safely | [`org-release`](../skills/org/org-release/SKILL.md), [`org-ethos`](../skills/org/org-ethos/SKILL.md) |
